### Project Overview

This project involved rebuilding a legacy corporate services website into an editable Webflow CMS platform. The migration allowed non-technical marketing team members to publish case studies, industry updates, and service offerings independently without engineering intervention.

### Context & Problem

The organization's original website was static, difficult to update, and lacked a unified design system. Content updates required manual HTML edits, leading to inconsistent styling and broken page layouts across different viewports. Furthermore, search engine indexing was hindered by missing metadata tags and non-semantic headings.

### My Role & Responsibilities

* **Figma to Webflow Translation:** Translated high-fidelity Figma components into clean, semantic Webflow layouts following responsive BEM naming conventions.
* **CMS Architecture:** Structured custom collection schemas for services, team profiles, and client case studies with intuitive editor controls.
* **Client-Side Filtering:** Wrote lightweight vanilla JavaScript to provide instant category and keyword filtering across case study archives without page reloads.
* **On-Page SEO:** Configured dynamic Open Graph meta tags, structured schema markup, and automatic sitemap generation.

### Approach & Implementation

1. **Design System Setup:** Defined global style guides for typography, color tokens, button variants, and spacing systems in Webflow.
2. **Collection Modeling:** Created relational CMS schemas linking team members, case studies, and respective service categories.
3. **Responsive Refinement:** Fine-tuned breakpoints for fluid responsiveness across phones, tablets, and ultra-wide screens.
4. **Editor Training & Handoff:** Prepared concise documentation guiding the marketing team through the publishing workflow.

### Outcome & Impact

* Enabled editorial staff to publish new content within minutes instead of waiting for code deployment cycles.
* Maintained 100% responsive visual fidelity with fast Core Web Vitals scores.
* Enhanced search engine discovery through semantic tags and structured data.
